Failed downloads

You can always retry a failed download from the Queue tab. If a show failed in the middle, the retry starts at the episode that failed, so nothing is downloaded twice.

Console tab
Pinned shows

This sends the show's name to TVmaze. A streaming service can publish a bit later than the TV air time. If the episode isn't there yet, the next regular check finds it.

Availability check

Shows what a title offers before you download it: resolutions, codecs, HDR and DV, every audio track and subtitle. It logs in and reads the track list, but never downloads anything and never asks for keys.

Account risk: every check logs in, just like a download does. Checking a service while it is downloading looks like several devices on one account at once.

External API

Lets your own scripts, such as a Discord bot, ask for downloads: they send a service, a link or ID and the quality they want, get back what's available, and confirm it. The API runs on its own port and only offers these calls, not this web page. How to use it is described in API.md.

Anyone who has the key can make this computer log in to your accounts and download. The API uses plain HTTP: to use it over the internet, put it behind a reverse proxy with HTTPS, or a VPN.
