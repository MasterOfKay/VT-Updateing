Console Progress Display

Only matters when you run vinetrimmer yourself in a terminal (cmd or shell). It decides whether you see live progress bars or simple "Downloaded: <track>" lines. Downloads started here in the web UI always show progress bars on the Console tab.

Console Tab
Experimental

Shows what a title offers before you download it: resolutions, codecs, SDR, HDR10, HDR10+, DV and DV+HDR, every audio track and every subtitle. You can then pick what you want. It logs in and reads the track list, but it never downloads anything and never asks for keys.

Account risk: every check logs in, just like a download does. Running a check while a download is running looks like several devices at once, and that is riskier for the account. So check first and download afterwards, one thing at a time.

This sends the name and year to IMDb. When it's off, a poster only shows if the service itself provides one.

Pinned Shows

This sends the show's name to TVmaze. The TV air time is a good guide, but a streaming service can publish a bit later. If the episode isn't there yet, the next regular check finds it.

Default Preferences

These values are filled in on the Download page for every service. You can still change them for each download. The command line uses them too when you leave the option out.

Failed Downloads

You can always retry a failed download from the Queue tab. If a show failed in the middle, the retry starts at the episode that failed, so nothing is downloaded twice.

If a retry gets further than the one before, the count starts again.

This only removes files that download created or changed. Other files in the temp folder stay. To empty the whole folder, use "Clean temp folder" under Storage.
